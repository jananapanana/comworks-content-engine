# /ce-learn <tenant>

Weekly feedback pass. Turns edits and metrics into proposed configuration changes.

1. Read posts changed since the last learn pass (the date is in the newest `runs/*learn*.md`): `Jana edit notes`, `Rejection reason`, metrics
2. Compare original draft (run log) and published copy where both exist. List the differences
3. Look for patterns across at least two posts: a word removed repeatedly, hooks shortened, a structure preferred, a pillar or format that performs above or below the others
4. For each pattern write one proposal: file, the exact line to add or change, the two or more examples behind it. Performance proposals are worded as "consider", they never change shares automatically
5. Show the proposals. **Stop.** The operator approves or rejects each one
6. Write approved changes into the file, append a dated line to that file's "Change log" section, record the pass in `runs/<date>-<tenant>-learn.md`

Never propose relaxing a hard check or anything in `rules.md`.
