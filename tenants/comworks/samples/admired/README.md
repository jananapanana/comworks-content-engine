## What this means for the voice profile

Jana's own posts define the sentences. These references define what a post is for: an evaluation of real work with numbers, a method others can copy, or a stated opinion backed by one chain of evidence. Three post types for the engine, mapped to pillars:

| Type | Pillar fit | Shape |
| --- | --- | --- |
| Evaluation | Build and hand over, Data before campaigns | Situation, what was measured, numbered findings, one takeaway |
| Method | AI as the method | Steps with time or tool per step, the prompt or rule included, what it replaced |
| Opinion | Opinions on GTM | Belief the market holds, the evidence against it, Jana's stance in first person |
