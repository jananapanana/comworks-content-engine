# Sample 3: Don't parse the title, ask the system that owns the field

Text only, Tuesday, LinkedIn personal. Board status Not started. Pillar: Build and hand over.

**Hook:** The course dates were inside the product title. Three formats, no rule.
**Alt hook:** Two days of parsing logic, replaced by one API call a week.

A school sells courses through a shop. The CRM gets the order. The course start and end sit inside the product name, written by hand, in three different formats.

Every parser I could write would break on the next variant.

The course platform behind it had start and end as fields, behind an API, one call. Two days of parsing logic replaced by a weekly pull.

Before you parse text, ask which system already owns the field.
